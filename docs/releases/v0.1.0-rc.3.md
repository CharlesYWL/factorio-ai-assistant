# Factorio AI Assistant v0.1.0-rc.3

第三个私有 release candidate，针对 rc.2 Windows 实机测试中暴露的 Chat 可读性与流程指南本地化问题。Mod 与 Companion 必须来自同一 rc.3 bundle 成对安装。

> **Steam 成就警告：** Factorio 启用任何 Mod 后，该存档都不能获得 Steam 成就。请先备份存档并使用测试副本。

本 RC 仅用于私有 GitHub Release 和 Windows 实机验收，不发布到 Factorio Mod Portal。

## 相对 rc.2 的变化

### 紧凑 Chat 回答
- 默认回答不再把 `[事实] / [流程指南] / [推断] / [缺失数据] / [假设] / [行动]` 全量审计结构铺在聊天窗口。
- 玩家视图只显示模型结论（若有）、当前阶段或关键事实、最多 3 条建议，以及最多 1 条必要的数据警告。
- 证据、assumptions、missing-data 与 tool call 仍保留在 Companion 的确定性上下文与测试中，数字冲突、提示注入和只读边界不变。
- 移除聊天卡片下方重复且容易截断的“数字 / 假设”扫描行。

### 流程指南 i18n
- Guide 的 objective、rationale、verification、阶段依据、下一目标、tool output 和最终 action 统一经过 `LocalizedNameLookup`。
- Mod 启动后预先请求内置指南涉及的科技、物品、流体与机器名称；中文游戏优先显示官方中文名，英文游戏显示官方英文名，翻译尚未返回时才回退 prototype ID。
- 新增火箭阶段回归测试，覆盖火箭发射井、混凝土、火箭燃料、电能蓄电、太阳能、效用科技包、三级速度/产能插件和雷达，确保玩家正文不再出现 raw kebab-case ID。

## Windows 重点复测
- “下一步做什么”默认回答应短、无全量审计区块，建议不超过 3 条。
- 火箭阶段建议应显示官方游戏语言名称，不出现 `rocket-silo`、`utility-science-pack` 等 raw ID。
- 聊天自动贴底、清空、常驻提醒/dismiss、聊天内确定性计算继续正常。
- 关闭 provider 后 35 秒内安全降级；关闭 Companion 后约 10 秒转 Offline，重启后恢复。
