# Factorio AI Assistant v0.1.0-rc.1

首个私有 release candidate。它把只读 Factorio 2.0 Mod、本机 Companion、生产比例
计算器、规则提醒和可选模型解释层打包为一套必须成对安装的版本。

> **Steam 成就警告：** Factorio 只要启用任何 Mod，该存档就不能获得 Steam 成就。
> 请先备份存档，并用专门的测试副本验收。

本 RC 仅用于私有 GitHub Release 和 Windows 实机验收，**不会自动发布到 Factorio
Mod Portal**。

## 资产

- `factorio-ai-assistant_0.1.0.zip`：直接放入 Factorio `mods` 目录的 Mod。
- `factorio-ai-assistant-companion-windows-x64-0.1.0.zip`：Node.js 22 Windows
  Companion、启动脚本、诊断脚本和示例配置。
- `companion.config.example.json`：无密钥的本地模式配置模板。
- `performance-baseline.json`：空闲、正常生产和接近 16 KiB 的大基地摘要自动基线。
- `SHA256SUMS`：上述文件的 SHA-256。
- `factorio-ai-assistant-v0.1.0-rc.1.zip`：包含全部资产、说明和校验值的总包；同目录
  `.sha256` 文件校验总包自身。

Factorio 的 Mod 版本格式不支持 prerelease 后缀，因此 Mod 内部版本为 `0.1.0`，
GitHub 候选标签为 `v0.1.0-rc.1`。

## 自动门禁

| 门禁 | 环境 | 覆盖 |
| --- | --- | --- |
| Build + unit/integration tests | Node.js 22，Ubuntu + Windows | TypeScript、UDP loopback、协议、状态、计算器、提醒、provider 降级、ZIP |
| Lint | Ubuntu | TypeScript/JavaScript ESLint、Lua 5.2 语法、Mod/UI 静态契约、中英 key |
| Release consistency | Ubuntu | 四个 npm/lock 版本、Mod/Companion 版本、协议版本、schema 版本、RC 标签 |
| Security/privacy | Ubuntu | 仅 `127.0.0.1`、远程 provider 凭据、日志脱敏、配置和消息上限 |
| Package verification | Ubuntu | ZIP 路径/CRC、必需资产、内嵌版本、SHA-256、bundled Companion `--version` |
| Performance baseline | Ubuntu | 空闲、正常、大摘要处理时间；30 分钟提醒冷却模拟 |

CI 产物中的 `performance-baseline.json` 是候选构建的实际数据。Node 基线不替代
Factorio 实机 UPS 验证。

## 安装与升级

按 [`docs/setup-windows.md`](../setup-windows.md) 安装，并按
[`docs/windows-smoke-test.md`](../windows-smoke-test.md) 完成 15–30 分钟冒烟测试。

Mod 和 Companion 必须来自同一个 release bundle。升级或降级时先退出 Factorio 和
Companion，再同时替换两者；保留自己的 `companion.config.json`。如果版本或协议不匹配，
游戏内状态页会显示双方版本并停止聊天、计算和新状态同步，不会在不兼容数据上继续运行。

## 已知限制与实机待验

- 当前自动环境没有 Factorio；Windows + Steam 图形界面、DPI、键盘焦点、防火墙和
  真实 Lua UDP 仍需实机确认。
- 真实存档的空闲、正常生产、大基地摘要三场景 UPS，以及连续运行 30 分钟无未处理异常，
  需按 [`docs/performance.md`](../performance.md) 记录。
- 紧凑计算器不解决复杂上游多配方歧义；需要时使用 JSON CLI。
- 模型请求取消只保证终止仍在执行的请求；已经进入 UDP 的响应可能先到达。
- Provider 故障会在 30 秒总预算内降级到确定性本地结果，但不会离线修改工厂。

在 Windows 实机项目全部通过前，本候选和 MYW-96 保持待评审状态。
